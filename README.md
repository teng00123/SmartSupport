# 服装AI售后助手

专注服装品类的AI客服助手，服务中小电商卖家。

## 核心功能
- 尺码智能推荐
- 材质洗涤指导  
- 退换货条件自动判断

## 技术栈
- 前端：微信小程序
- 后端：Python + FastAPI
- 数据库：MySQL + Redis + MongoDB
- AI：规则引擎 + 轻量ML模型

## 项目结构
```
clothing-customer-service/
├── backend/          # Python FastAPI后端
├── frontend/         # 微信小程序前端
├── ai/              # AI模型和规则引擎
├── docs/            # 项目文档
└── deploy/          # 部署配置
```
